# Поиск определений в Black's Law Dictionary

Программа читает термины из `input.txt`, ищет соответствующие статьи в единственном PDF-файле из корневой папки проекта и записывает определения в `output.txt`. Она не обращается к интернету или другим словарям.

## Почему именно этот репозиторий?

Он позволяет отправить на поиск в словаре сразу много слов разом. Он абсолютно бесплатный и с открытым исходным кодом. Выдаёт более точный результат: все детали из словаря будут перенесены. 

## Важное о работе с программой

Все глаголы должны быть в инфинитиве. Регистр не важен.
Программа актуальной версии не различает части речи и реже находит словосочетания (если в строке 2+ слова).

Результат появится в `output.txt`. Пустые строки во входном файле игнорируются. Если точного заголовка нет, программа также проверит обычную форму единственного числа (например, `cases` → `case`). Если статья всё равно не найдена, она запишет об этом сообщение. В корневой папке должен находиться ровно один PDF-файл.

Если термин в словаре содержит побочные определения, которые вставлены между определениями основными, то программа, чаще всего, выписывает первое основное определение и может захватить ближайшее побочное. Например для `misconduct`, которое имеет 2 основных и 8 побочных определений, программа выпишет 1 основное и 1 побочное (о котором её вообще не просили). Все мои попытки исправить данный момент заканчивались значительным увеличением ошибок при поиске других слов, так что в актуальной версии я всё оставил как есть. Если вы читаете этот абзац, значит проблема всё ещё не решена.

# Как запустить приложение?
Сразу скажу - я не тестировал приложение на других устройствах/виртуальных машинах. Так что есть вероятность, что у Вас оно может просто не запуститься по какой-то магической причине.

## Для пользователей Windows

1. Распакуйте архив с программой в любую папку.

2. **Первый запуск:** дважды кликните на `install.bat`.
   - Скрипт сам скачает и установит Poppler в папку с программой.
   - Требуется подключение к интернету.
Примечание: Если у вас есть активные proxy (Cloudflare WARP, VPN-сервисы) это может помешать установке нужных зависимостей. При появлении предупреждения безопасности стоит ввести `A`. Если вы беспокоитесь о своей безопасности - установите Popper через PowerShell, инструкцию можно найти в интернете.

3. **Работа:** дважды кликните на `dictionary_search.exe`.
   - Результат появится в `output.txt`.

4. Не забудьте перед запуском обновить слова в `input.txt`

## Для пользователей macOS

1. Откойте консоль и установите зависимости:

   ```sh
   brew install poppler cmake
   ```

2. Запустите приложение из корня проекта:

   ```sh
   "путь до папки"/dictionary_search
   ```

3. Не забудьте перед запуском обновить слова в `input.txt`

## Для пользователей Linux

Вы сами разберётесь. 
Если вы считаете это слишком сложным, то Вам стоит попросить своего личного системного администратора помочь вам. Он же у Вас есть, верно?

### Пересборка проекта
Данный вариант кроссплатформенный. Исполняемый файл `dictionary_search` (или `dictionary_search.exe` для Windows) появится в корне проекта.

```sh
cmake -S . -B build  
cmake --build build --config Release
```
